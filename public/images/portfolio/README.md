# Portfolio company logos

Generated by `scripts/prepare-supplied-assets.mjs` from the originals in
`assets-supplied/`. Seven are byte-for-byte copies; two needed mechanical
preparation, both documented in the script:

- **`memmo.svg`** — the supplied file is an 810 × 810 artboard with a 639 × 98
  wordmark floating in the middle, which `object-fit: contain` would shrink to a
  fraction of the frame. The viewBox is narrowed to the artwork's own bounding
  box. No path is touched.
- **`newly.png`** — supplied as an A4 PDF with the square logo tile placed
  sideways on it. Rendered at 121 dpi, cropped to the tile, and rotated one
  quarter-turn clockwise. The rotation is a pure pixel remap, so nothing is
  resampled.

Each company records the field its artwork needs in `Company.logoSurface`, set
from measured luminance: Agaton, Openroll and Memmo are dark marks that need a
light field; the rest are light marks that need a dark one.

`BuilderBase_Logotype-Primary-Black.png` was supplied but is **not** published —
BuilderBase is not one of the eight companies on the live portfolio. See
`content-quarantine/README.md`.
