# Fonts

`IvarDisplay-Regular.woff2` belongs here.

Ivar Display is identity-bearing for Foundry (headings, large quotes, editorial
statements). The copy currently served from the live Squarespace site is an
**identification reference**, not automatically a redistributable asset — confirm the
licence and obtain the original WOFF2 from the rights holder before adding it.

While the file is absent, `--font-display` resolves to a metric-adjusted Georgia
fallback and `pnpm fonts:check` prints a development warning. Inter is never an
acceptable substitute.
